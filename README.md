# FIT3179 Starter

This starter contains the first Vega-Lite visualisation and a simple single-page layout.

Files:
- index.html
- css/style.css
- js/chart1_lookout_map.json
- data/scenic_walks_lookouts.csv

Run locally with VS Code Live Server:
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Choose "Open with Live Server".
